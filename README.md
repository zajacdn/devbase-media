# devbase-media

Превью шаблонов CapCut/TikTok, которые использует портал [devbase](https://zajacdn.github.io/devbase/).

- `t/<video_id>.mp4` — превью 480p, h264, без звука
- `p/<video_id>.jpg` — постер

Источник: TikTok [@capcut__791](https://www.tiktok.com/@capcut__791).
Репозиторий — только медиа-хостинг через GitHub Pages. Права на шаблоны принадлежат их авторам.
